ATHOS ICONS – DEMO
==================

Ελληνικά παρακάτω.

This is a working copy of the shop that runs only on your computer. Nothing is really sent,
paid or published, so try everything: order, create an account, use the admin panel.

HOW TO START
------------
Windows
  1. Right-click the zip file and choose "Extract All", then open the extracted folder.
  2. Double-click "Start Demo".
     If Windows says "Windows protected your PC": click "More info", then "Run anyway".
  3. A black window opens and, after a few seconds, the shop opens in your browser.

Mac
  1. Double-click the zip file to unzip it, then open the folder.
  2. Right-click (or Control-click) "Start Demo.command" and choose "Open", then "Open" again.
     On newer macOS versions: double-click it, click "Done", then open
     System Settings > Privacy & Security, scroll down and click "Open Anyway".
  3. A Terminal window opens and the shop opens in your browser.

Linux
  1. Unzip the file and open the folder.
  2. Right-click "start-demo.sh" and choose "Run as a Program"
     (or open a terminal in the folder and type:  ./start-demo.sh ).

Keep the black/Terminal window open while you use the shop. Close it to stop the demo.
If the browser did not open, go to the address shown in that window (usually http://127.0.0.1:8000).

EMAILS
------
The demo does not send emails. Every email the shop would send (to customers and to you)
appears on the "Demo mailbox" page, linked in the blue bar at the top of the shop.
To create a new account, open the confirmation email there and click its link.

START OVER
----------
Close the demo, delete the "data" folder inside the demo folder, and start it again.


ΕΛΛΗΝΙΚΑ
========

Αυτό είναι ένα λειτουργικό αντίγραφο του καταστήματος που τρέχει μόνο στον υπολογιστή σας.
Τίποτα δεν αποστέλλεται, δεν πληρώνεται και δεν δημοσιεύεται, οπότε δοκιμάστε τα όλα:
παραγγελίες, δημιουργία λογαριασμού, διαχείριση.

ΠΩΣ ΞΕΚΙΝΑ
----------
Windows
  1. Δεξί κλικ στο αρχείο zip > «Εξαγωγή όλων» και ανοίξτε τον φάκελο που δημιουργήθηκε.
  2. Διπλό κλικ στο «Start Demo».
     Αν εμφανιστεί «Τα Windows προστάτεψαν τον υπολογιστή σας»: «Περισσότερες πληροφορίες» > «Εκτέλεση οπωσδήποτε».
  3. Ανοίγει ένα μαύρο παράθυρο και σε λίγα δευτερόλεπτα το κατάστημα ανοίγει στον browser.

Mac
  1. Διπλό κλικ στο zip για αποσυμπίεση και ανοίξτε τον φάκελο.
  2. Δεξί κλικ (ή Control-κλικ) στο «Start Demo.command» > «Άνοιγμα» > «Άνοιγμα».
     Σε νεότερες εκδόσεις macOS: διπλό κλικ, «Τέλος», μετά Ρυθμίσεις συστήματος >
     Απόρρητο και ασφάλεια, κάντε κύλιση προς τα κάτω και πατήστε «Άνοιγμα ούτως ή άλλως».
  3. Ανοίγει ένα παράθυρο Τερματικού και το κατάστημα ανοίγει στον browser.

Linux
  1. Αποσυμπιέστε το αρχείο και ανοίξτε τον φάκελο.
  2. Δεξί κλικ στο «start-demo.sh» > «Εκτέλεση ως πρόγραμμα»
     (ή σε τερματικό μέσα στον φάκελο:  ./start-demo.sh ).

Αφήστε το μαύρο παράθυρο / Τερματικό ανοιχτό όσο δοκιμάζετε. Κλείστε το για να σταματήσει το demo.
Αν δεν άνοιξε ο browser, πηγαίνετε στη διεύθυνση που δείχνει το παράθυρο (συνήθως http://127.0.0.1:8000).
